# columns-checklist

Custom **columns** block. Purpose: Checkmarked benefit or eligibility list laid out in two (or more) columns.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One or more rows; each cell is a column holding a bulleted list (each item: bold label, optional description, optional link or info button). A cell without a list has each paragraph treated as one item. A single-cell list flows into two columns on desktop. Empty cells are dropped.

## Supported variations

No variations.

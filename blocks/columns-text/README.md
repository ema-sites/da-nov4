# columns-text

Custom **columns** block. Purpose: Fixed side-by-side text columns: label/description rows, icon + heading + text benefit columns, link/question lists and image + text pairs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one or more rows of N cells (usually 2-3). Each cell holds text (optional leading icon picture, heading, paragraph, list, links); a cell with only a picture is an image column. Two-cell rows render as label/value rows.

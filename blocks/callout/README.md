# callout

Custom **custom** block. Purpose: highlighted notice or promo box (security guarantee, important notice) with optional icon, heading, text and link; also a small offer badge or a one-line link strip.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per callout item (usually one). Cells: optional icon/image cell (picture only) | content cell (heading, text, link). Cells may be merged into one; picture-only cells become the icon, everything else the body. Extra rows render as stacked items.

## Supported variations

| Variation | Option class |
| --- | --- |

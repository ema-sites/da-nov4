# product-details

Custom **custom** block. Purpose: Product page body for an account or card: intro box, icon benefit lists, rewards promo, product image with price and offer, and side-by-side ideal/not-ideal panels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per panel. A row with one cell is a full-width panel (heading, text, lists, links). A row with an image-only cell plus a content cell is a media panel (product image beside name, price, benefits, CTA). A row with two or more content cells renders those cells side by side (e.g. pros and cons). Lists whose items begin with an icon or image become icon feature lists; a link alone in a bold/italic paragraph becomes a button.

# anchor-nav

Custom **custom** block. Purpose: Horizontal in-page jump-link bar (e.g. Key Features, Banking Fees, How to Open) linking to sections of the same page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One or more rows whose cells hold links (a list of links or one link per cell); all links are collected into one horizontal list. Rows with no links are kept as plain side-by-side text cells.

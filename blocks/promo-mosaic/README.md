# promo-mosaic

Custom **custom** block. Purpose: Bento-style mosaic of mixed-size promotional tiles: one tall feature tile beside a stack of smaller supporting tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; each row has an optional image-only cell (tile media/illustration) and a content cell (heading, short text, CTA button and/or link). The first row is the tall feature tile.

## Supported variations

| Variation | Option class |
| --- | --- |
| Orange Light | `orange-light` |
| Light | `light` |
| Mirrored | `mirrored` |
| Alt | `alt` |

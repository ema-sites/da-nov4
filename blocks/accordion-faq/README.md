# accordion-faq

Custom **accordion** block. Purpose: FAQ questions that expand to answers, optionally grouped by topic or paired with an image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Rows of two cells: question | answer (one collapsible item per row). Optional single-cell rows: a picture (shown beside or behind the list for image-beside / background-image options), intro text before the first question, and, with the grouped option, a heading row that starts a new topic group (groups longer than 3 items get a Show More toggle).

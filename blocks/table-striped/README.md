# table-striped

Custom **table** block. Purpose: Striped fee/feature data table with a header row and row labels in the first column, optionally behind an expander.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: first row: column headers (one cell per column); each further row: a row label cell followed by value cells. A row with a single cell spans all columns. With the collapsible option, an optional first single-cell row is the expander label. A cell containing only ✓ or ✗ renders as the blue check / black cross icon.

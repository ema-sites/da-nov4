# accordion-legal

Custom **accordion** block. Purpose: Collapsed legal disclaimer toggle, usually at the bottom of the page, that expands to show fine print.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: cell 1 is the toggle label; optional cell 2 is a summary that stays visible under the toggle when more rows follow (or the disclaimer body when it is the only row). Rows 2+: disclaimer body content (paragraphs, lists, footnotes), hidden until opened.

# breadcrumb

Custom **custom** block. Purpose: Breadcrumb trail at the top of a page showing the path from the site root to the current page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: A list of links (or one link / text per cell or paragraph). Linked items become ancestor crumbs; trailing plain text is the current page. Use the alt option for trails that end on a linked item with a trailing separator.

## Supported variations

| Variation | Option class |
| --- | --- |
| Alt | `alt` |

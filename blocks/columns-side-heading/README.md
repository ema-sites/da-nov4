# columns-side-heading

Custom **columns** block. Purpose: Section heading in a narrow left column with rich content (benefits, key-feature lists, fee/rate tables, steps) in a wide right column.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one or more rows: first cell holds the section heading; second cell holds the content (paragraphs, sub-headings, lists, tables, links/buttons). Extra cells sit side by side in the right column; with boxed-cards each is a bordered card (optional icon + heading header), with boxed-panel the right column is one bordered panel.

## Supported variations

| Variation | Option class |

# columns-resources

Custom **columns** block. Purpose: Resource link list (or body copy / expandable feature list) beside one or more bordered cross-sell cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: first cell is the lead column (heading plus link list, body copy, or with accordion sub-headings each followed by their content); each further cell is a bordered card (optional image, heading, text, trailing link paragraph as the CTA). With feature-panels every cell is an equal panel. Pictures inside link lists are treated as icons (shown beside the link); with feature-panels a picture closing a panel runs to the panel edges.

## Supported variations

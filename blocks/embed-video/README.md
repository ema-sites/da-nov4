# embed-video

Custom **embed** block. Purpose: Embedded video player (YouTube, Vimeo, mp4) optionally behind a poster image with a play button; several videos sit side by side.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per video: optional poster image, the video URL as a link, optional caption text. Two or more rows render as a two-up grid.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Dark Light | `image-dark-light` |

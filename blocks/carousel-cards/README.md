# carousel-cards

Custom **carousel** block. Purpose: Horizontally scrolling row of promo, offer or article cards with prev/next arrows and a progress bar, optionally beside an intro panel; text-slides options turn it into one centred text slide at a time with dots.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional first row: one cell with an h2 intro (logo image, heading, text, link) shown beside the cards. Every following row is one card: an optional picture-only cell (card image) plus a body cell (heading, text, links/buttons). With text-slides / text-slides-2 each row is one full-width text slide (heading, text, link) and there is no intro row. Empty rows and cells are ignored.

# section-nav

Custom **custom** block. Purpose: In-section navigation: a list of links to sibling pages, shown as a toggle menu, a sidebar menu or a row of tab-style links, with the current page marked.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row with the section title (heading or text, used as the menu toggle label); then one row per link (optional icon/image cell plus a link cell), or a single cell holding a bulleted list of links.

## Supported variations

| Variation | Option class |
| --- | --- |
| Sidebar | `sidebar` |
| Horizontal Tabs | `horizontal-tabs` |

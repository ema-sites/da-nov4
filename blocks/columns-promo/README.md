# columns-promo

Custom **columns** block. Purpose: Bordered promotional box pairing a photo or illustration with a heading, short copy and a CTA (link, button or phone number).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one or more rows, each with an image cell (picture only) and a content cell (heading, paragraph, list, links/buttons); either may come first. With side-box, a third cell becomes a separate box (e.g. sign-in prompt) beside the promo.

# product-selector

Custom **custom** block. Purpose: Choose-one product finder: a question with radio options (optionally illustrated), an option picker that reveals a product detail panel, and a CTA that follows the selected option.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional first row: one cell with heading and intro text. Optional single-cell text row: the question (legend). Option rows: cell 1 = option label (optional image/icon, text, link to the result page), cell 2 = optional detail panel shown when selected (name, price, included features, CTA). Optional last row: one cell holding only a link, the CTA whose href follows the selected option.

## Supported variations

| Variation | Option class |
| --- | --- |
| Shadow Light | `shadow-light` |
| Blue Light | `blue-light` |
| Image Light | `image-light` |
| Image | `image` |
